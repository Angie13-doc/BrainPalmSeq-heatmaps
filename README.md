# BrainPalmSeq 2026 heatmap release

Upload the **contents of this folder** to the root of https://github.com/Angie13-doc/BrainPalmSeq-heatmaps (not the enclosing release folder).

Each dataset has its own subfolder, with matching `.html`, `_data.csv` and `_iframe.html` files. Use `WORDPRESS_EMBEDS.md` for WordPress iframe URLs.

Original source expression values were not renormalized. Phillips thalamic nuclei log2 CP10K normalization is provisionally assigned at the user’s direction, not independently verified. NA values remain missing.

See VALIDATION_REPORT.csv for counts and omissions. Browser rendering was not exhaustively tested.
